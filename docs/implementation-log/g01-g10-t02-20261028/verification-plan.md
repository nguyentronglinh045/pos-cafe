### 3.4 Dữ liệu cần thu cho mỗi biến thể

Theo quy tắc bằng chứng tại `@docs7df` `docs/workflow/README.md:78`: source phải là commit sạch, hoặc baseline + fingerprint cùng snapshot/patch phục hồi được, gồm cả file mới và code test.
